# Участие в разработке

Спасибо за интерес к Atlas App Window. Перед крупным изменением создайте issue с описанием целевого
ГУ, версии Android/OEM-прошивки и ожидаемого поведения.

## Локальная проверка

Нужны JDK 17 и Android SDK 36. Перед pull request выполните:

```sh
sh gradlew --offline clean check assembleRelease
```

Если нужные зависимости ещё не находятся в локальном Gradle cache, один раз запустите команду без
`--offline`. Не добавляйте в коммит APK, `local.properties`, signing-конфигурацию, keystore, ADB-ключи
или дампы устройства.

## Требования к изменениям

- Не заявляйте универсальную поддержку Android: freeform зависит от OEM-прошивки.
- Не заменяйте интерактивную Activity скриншотом MediaProjection или coordinate input injection.
- Не выполняйте `force-stop` при обычном переключении и не изменяйте task без точной проверки
  владельца.
- Проверяйте все внешние extras и shell output; shell-команды должны собираться только из строгих
  allowlist-значений.
- Платформенную/OEM/ADB-логику оставляйте на границах адаптеров, а чистую логику покрывайте JVM-тестами.
- При изменении приложения увеличивайте `appVersionCode` и `appVersionName` в начале
  `app/build.gradle`.

## Проверка на устройстве

Изменения поведения окна требуют проверки на целевом Android 11 ГУ: touch внутри и снаружи окна,
IME, switching, relaunch, sleep/wake и восстановление после потери ADB. Результат эмулятора нельзя
выдавать за подтверждение OEM-поведения.

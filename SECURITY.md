# Security policy

## Supported versions

До появления стабильной ветки исправления безопасности принимаются только для последней версии в
ветке `main`.

## Сообщение об уязвимости

Не публикуйте рабочий exploit, ключи подписи, ADB-ключи или дампы устройства в открытом issue.
Используйте GitHub Private Vulnerability Reporting в разделе **Security → Advisories → Report a
vulnerability**. Если эта функция недоступна, создайте issue без чувствительных деталей и попросите
владельца репозитория предоставить приватный канал связи.

В сообщении укажите версию приложения, версию Android/OEM-прошивки, шаги воспроизведения и влияние.
Логи необходимо очистить от компонентов, идентификаторов устройства, ключей и других секретов.

## Граница доверия

Внешние intent extras и вывод shell считаются недоверенными. Публичный API принимает только
локальные preset ID. Atlas не должен выполнять shell-команды с произвольными строками, делать
package-wide `force-stop` или изменять задачи, которые не были точно связаны с выбранным компонентом.
